# Insider Trading with Noisy Information

This repository contains the numerical implementation for the dissertation  
**"Insider Trading with Noisy Information: A Filtration Enlargement Approach."**

## Files

- `main.ipynb` contains the complete numerical analysis.
- `AAPL_2021_2025.csv` contains the historical Apple stock price data used in the analysis.
- The `.csv` and `.png` files contain numerical results and figures generated by the notebook.

## Running the Code

Open `main.ipynb` and run all cells from top to bottom.

The notebook performs the full numerical analysis, including parameter estimation, Monte Carlo simulation, construction of noisy insider information, conditional expectation estimation, information drift estimation, semimartingale diagnostics, and filtration enlargement strength analysis.

The figures and numerical outputs used in the dissertation are generated by the notebook.
